### :dataframe-compiler-plugin-core

Subset of :core used by [compiler plugin](https://github.com/JetBrains/kotlin/tree/master/plugins/kotlin-dataframe) to implement compile time interpreters of operations.
Bundled together with the compiler plugin in Kotlin and, by extension, in IntelliJ. Should aim to include only the necessary code.

See [Compiler Plugin](https://kotlin.github.io/dataframe/compiler-plugin.html) for what the plugin this module is
bundled into does for a user.
