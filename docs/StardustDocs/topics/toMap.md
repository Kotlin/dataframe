[//]: # (title: toMap)

Converts [`DataFrame`](DataFrame.md) into `Map<String, List<*>>` from column names to column values.
The returned value lists are new copies: changing them doesn't affect the `DataFrame`.

**API reference**: [`toMap`](https://kotlin.github.io/dataframe/api-docs/core/org.jetbrains.kotlinx.dataframe.api/to-map.html)

```
toMap()
```
