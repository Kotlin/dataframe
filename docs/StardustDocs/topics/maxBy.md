[//]: # (title: maxBy)

Returns the first [row](DataRow.md) that has the largest value in the given column, 
or throws an exception if [`DataFrame`](DataFrame.md) is empty.

**API reference**: [`maxBy`](https://kotlin.github.io/dataframe/api-docs/core/org.jetbrains.kotlinx.dataframe.api/max-by.html)

## maxByOrNull

Returns the first [row](DataRow.md) that has the largest value in the given column, 
or `null` if [`DataFrame`](DataFrame.md) is empty.
